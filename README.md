## About the Project
**La Vella** is an educational pet project created to explore backend engineering with Spring Boot. The point is to simulate the optimised system for our favourite, but highly inefficient cafeteria "La Vella" at our campus **ETSINF** at **UPV (Universitat Politècnica de València)**.

The main goal of a project is to learn the architecture, master OOP principles and practice the codewriting. Our main goal is education, so not a single line of code here was written by AI, even though it is of course used as an educational tool.

## Tech Stack
* **Java 25**
* **Spring Boot 4.1.0**
* **Spring Web** (REST API)
* **Spring Data JPA + Hibernate**
* **Database:** H2 (in-memory database for active local development, with a planned migration to **PostgreSQL**)
* **Lombok & Bean Validation**
* **Maven**
