# La vella - первый проект в 2026 без ИИ-слопа
Хочу задать хороший тон и весь readme напишу от руки. // перед релизом подредачим и переведём.  
Суть проекта: Учебный пет-проект который будет имитировать работу с заказами в кафетерии La vella в кампусе estinf UPV.  

## Cтатус  
В разработке.
## Стэк  
- Java 25
- Spring Boot 4.1.0
- Spring Web (REST API)
- Spring Data JPA + Hibernate
- H2 (in-memory база на время разработки, после чего надо будет разобраться с PostgreSQL)
- Lombok, Validation
- Maven
